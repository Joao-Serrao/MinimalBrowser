Minimal Browser

A lightweight, distraction-free Android browser built around WebView — split-screen browsing, gesture controls and ad blocking, with no tabs and no clutter.

Download APK All releases

Free and open source · Requires Android 7.0 (API 24) or newer

Features

Split-screen browsing

Two pages at once instead of tabs. Drag to resize, swap panes, and it adapts to portrait and landscape.

Search-first

DuckDuckGo by default. Type a URL to go straight there, or anything else to search.

Ad & tracker blocking

Blocks ad and tracker domains at request level, cancels redirect-to-ad taps, and suppresses popups.

Gesture controls

Swipe the search bar to go back, double-tap to resize panes, and hide the bar for a full screen.

Immersive full-screen

Status and navigation bars stay hidden, with proper full-screen video playback.

Home screen widget

A search widget that opens the browser straight into the search field.

Installing

  1. Tap Download APK above on your Android phone.
  2. Open the downloaded file. Android will ask permission to install from this source — allow it.
  3. Tap Install. To add the widget, long-press your home screen → Widgets → Minimal Browser.

Why the warning? The app is not distributed through the Play Store, so Android flags it as an unknown source. The APK is signed and built from the source in this repository — you can build it yourself with ./gradlew assembleRelease.
